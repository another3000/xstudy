## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **痛点 → 小工具 → 一句可复制提示词** → AI入企：发「审批意见要让模型读得懂」；给科室一个固定批注格式，并附上一句「请按标注修改，未标注处不要动」。
2. **对比实测写失败模式** → 微李玩AI / 小程序：新视频模型或新流程不要只报「更清晰」，并列「会漂、会串、会闪」和触发条件（大幅运镜、群演）。
3. **金额到分的成本账本** → LIS / 输血信息化：一次质控抽检或一份报告解读的 Token 成本写成「单次 X 分 / 单日约 Y 元」，对照人工复核工时。
4. **自己被卡住的现场** → 小程序：先写「Agent 退出后端口还占着 / 后台一堆遗留进程」，再给查看器——比功能列表更像真用过。
5. **引用时补一句可执行修正** → 微李玩AI：看到「国内安卓上架好难」，不要只转，补「四家商店能自动同步，传一家即可」这类可核对经验。

## 8. 风险与不该学

- Bio 自报时间线含 R18 / 二次元，**医疗与院内品牌不要学这种混流**，否则信任先被冲掉。
- 赠金/领福利帖书签极高，但内容会过期，也容易被看成营销号；一年最多复用一两次「额度还没用完」即可。
- 纯表情、纯「恭喜」「8 月了」能借到几千曝光，书签为零——会把账号训练成评论员，而不是建造者。
- 「蓝色大肥鱼当监工，一边刷短剧」这类生活吐槽（799曝 / 书签0）对专业号是噪音。
- 不要把「无业、卖课为生」的自嘲口吻直接搬到公司账号。
