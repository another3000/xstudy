## 1. 一句话定性

V2EX 创始人把自己的「个人 VM 云」exe 公开建造：近窗用**一个 Go 二进制 + 欢迎向导 + 集群监视器**证明产品在跑；学他的发车附件，不学高曝低信息的怀旧视频当主线。

## 2. 人设与定位

- **Bio 承诺：** 只有 self-efficacy maxi。几乎不自我介绍，把证明留给产品。
- **时间线实际：** 从 8 月起「基本上住在 exe 里」：一个 Go 二进制提供操作 Claude Code 的 PWA，装到 Mac mini 或类似常开设备上，就不必担心合上笔记本或掉线。随后是新安装欢迎屏和配置向导、信息密度导向的多会话界面、exe 2026.11.11 的集群 Activity Monitor，以及「又可以退订 TradingView」这种用产品替换付费工具的旁证。旁支包括：给 Claude 一个目标并让它直播突破、在 PowerPC G4 / Mac OS X Tiger 上连回现代 NVIDIA 工作站、为失去资金的 IPFS/kubo 准备自己的 fork。
- **目标受众：** 想自己托管 Agent 和开发环境的建造者，以及仍记得 V2EX / 老 Mac 的华语技术读者。
- **差异点 / 人设钩子：** **产品自己会说话。** 安装地址、向导截图、版本号和「unsubscribed a paid tool」比任何身份标签硬。
- **与 Bio 的错位：** Bio 不提 V2EX，也不提 exe。新读者可能不知道这是谁；老读者靠作品认人。这是有意识的克制，不是定位混乱。

## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **发车必带「装到哪 + 解决了哪件日常麻烦」** → 小程序 / AI入企：不要只写「我们上线了 Agent」，写成「装在常开的一台工位机上，合上笔记本也不会断」。
2. **把第一次打开拍成欢迎向导** → LIS / 小程序：新用户前三步做成向导截图，而不是丢一份说明书。
3. **版本号 + 一条新能力 + 文档链接** → 对照 2026.11.11 Activity Monitor：更新日志不要罗列十个优化，只带一个能看懂的能力。
4. **用「我退掉了某个旧工具」当证明** → 微李玩AI：能写「以前用 X 看状态，现在用自己的页面就够了」。不要空说替代，要说退订了什么。
5. **设计原则写成一句可复述的话** → 「info density oriented design for many concurrent sessions」。院内多任务台可以先写原则，再放图。

## 8. 风险与不该学

- Bio 过短适合已经有名的人；微李玩AI 这类内容品牌仍需要一句能看懂的承诺。
- 怀旧视频可以偶尔出现，当主食会把产品日志冲掉。
- exe 更新里的 Solana/代币图表是产品旁支，**医疗与院内品牌不要学加密行情模块**。
- 「live broadcast of progress」适合自己的实验，对医院客户要改成可回放的进度记录，而不是表演过程。
