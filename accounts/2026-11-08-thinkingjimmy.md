## 5. 增长机制拆解

1. **互关 / 粉关比：** ≈28.6:1——健康。关注 653 对万粉级华语号属于正常社交半径，未见互关刷屏。
2. **回复工时：** 低。增长不靠串门，靠偶尔一篇报告长文被收藏。
3. **钩子话术：** 「或许有些暴论」、编号【1】【2】、「实际要看的是两个价格」、引用发布会后给出战略一句。
4. **书签型 vs 虚荣赞：** 编号实测与报告长文书签/赞可达 1–2；愿望短句高回复、零书签。公开、可核对的用法说明比情绪句值钱——这也符合「书签约等于私下想回来用」的信号（部分算法解读里书签权重远高于赞）。
5. **权威资产：** 自己的 Claude/Codex 用量对照截图、X Article 精读（Stack Overflow 2026、企业 ROI 报告）、长尾开源 comflowy-nodes。不是头衔号，是「账本号」。
6. **跨平台 / 漏斗：** 长文留在 X Article；老帖导向 newsletter 与 GitHub。漏斗是：引用进场 → 编号帖/长文书签 → 「这个人会算总价」的信任。近窗看不到强产品转化口。
7. **其他：** 引用大厂发布会（OpenAI）可借到曝光，但若自己只给判断不给清单，赞和书签都起不来（见 Top5#1 的 0 赞）。

## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **「两个价格」算法** → 微李玩AI：发「API 单价便宜 ≠ 跑完院内任务便宜」；并列完成一次真实检验流程的 Token 总价，和套餐额度摊下来的实际单价。
2. **编号分档用法** → AI入企：写清「日常录入/规则校验用中档，方案讨论/异常解读用高档」，避免全员默认 Max。
3. **暴论钩 + 报告兑现** → 微李玩AI：标题可以刺耳（「AI 没裁员，却关掉校招」），正文必须落到可核对来源（他引用了 Wharton/KPMG/Pax8 与 Stack Overflow 2026）。
4. **影子 IT 指数** → LIS / 输血信息化：他转的企业匿名使用榜提到「员工自己装的，不是公司统一采购」。可迁成：院内部署要先盘点科室私自用的模型/插件，再谈统一网关。
5. **引用时补一句真痛点** → 小程序：看到开源录屏工具不要只说「不错」，要写下自己的横竖屏一次编辑需求——痛点比称赞更能让人记住。

## 8. 风险与不该学

- 空盼帖（「我只希望 XX 能媲美 YY」）有回复无收藏，医疗品牌发这种像站队，不像专业。
- 战略分叉长判断如果只挂在别人的发布会上，容易变成「借光评论员」；要补自己的用量或客户现场。
- 全号 356 帖说明他走的是极低产路线，**不要误学成「少发就会涨」**——他靠的是判断密度，不是沉默本身。
- 硬件玄想（Mac Mini + NAS）有画面无数字，LIS 场景里没有单次检测成本就不要发想象帖。
