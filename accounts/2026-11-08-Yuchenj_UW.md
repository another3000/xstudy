## 5. 增长机制拆解

1. **互关 / 粉关比：** ≈348:1——非常健康。关注 887，与 30 万粉完全匹配。
2. **回复工时：** 中。热帖下讨论多（computer use 帖 257 条回复），他会再开主帖回答「为什么」。
3. **钩子话术：** 四词判决、听说体、编号预测、借 Karpathy/OpenAI 的当日新闻、对比句（Codex vs Claude）。
4. **书签型 vs 虚荣赞：** 配置清单和补丁列表书签密；迷因金句和传言句赞多存少。这和「书签是私下想回来用的信号、赞是情绪共振」对得上：Karpathy 配置可以被照抄，护城河形容词不太能。
5. **权威资产：** Databricks 在职、OctoAI 被收购、Hyperbolic、TVM、UW PhD；置顶仍是可核对的训练数字（150B tokens、HellaSwag 35.5%）。产品侧抛出 Smart Routing 省内部编码成本 35%。
6. **跨平台：** 引用论文、Karpathy 博客、公司产品（AI Gateway、Kimi Day 0 上架）。
7. **漏斗：** 金句进场 → 配置/预测清单被收藏 → 相信这个人在前线 → 偶尔导向 Databricks。注意：AI Gateway 销售帖只有 4.4 万曝，说明**转化帖没有自动继承金句流量**，要用同样具体的数字和场景重新挂钩。

## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **金句 + 次日清单二连** → 微李玩AI：先发一句刺耳判断，第二天必须补「护城河其实是这些」的可存列表，避免停留在情绪层。
2. **挂在当日权威配置上说话** → AI入企：不要空喊「别用终端」，要写成「XX 今天默认用桌面端 + 中档推理，因为大多数任务不需要最高 effort」。
3. **computer use 把 UI 变成 API** → LIS / 输血信息化：老检验系统、血库界面、报销和物资系统往往没有可用 MCP。演示一次「Agent 在旧界面上点完危急值复核」，比等待厂商开接口更快证明价值。
4. **Number Drop 引用大厂安全实验** → 微李玩AI：948 个漏洞 / 120 万美元是可引用的公开数字；迁到院内要改成「扫一遍规则引擎要多少钱、漏掉一条会怎样」。
5. **产品帖必须重新挂钩** → AI入企：Gateway 那种「省 35%、Day 0 上模型、按团队设预算」写法是对的，但不要指望昨天的迷因会把它带火——要单独用账单钩重开一条。

## 8. 风险与不该学

- 短金句上瘾：只发「There is no moat」而不发补丁，账号会变成名言日历。
- 「听说硅谷……」传言体在医疗场景会削弱专业感，除非后面有公开数据。
- 产品安利口吻（Choose Databricks…）可以直接学结构，但医院客户反感硬广，要把「选我们」改成「这是我看到的账单问题」。
- 置顶还是两年前的训练日志——长尾权威有效，但近窗人设已经转向 Agent 接口，新旧之间要自己讲圆。
