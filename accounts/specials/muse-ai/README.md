## 产品是什么（先对齐）

**Muse** = Meta 于 2026-09-08 起推的个人 AI Agent（华语常称 Muse.AI / Meta Muse）。官网 [muse.ai](https://muse.ai)，官方账号 [@Muse](https://x.com/Muse)。跑在 **Muse Secure VM**（一人一机云电脑+浏览器），敏感动作（发信、下单等）需本人确认；产品心智含 Chat / Goals / Artifacts / Connectors。

对标记忆：**Grok Bot 偏工作多 Bot；Muse 偏生活管家**（蓝哥公开回复）。本专题学「可逆全自动、不可逆人审」与「任务四件套」写法，不学区锁灰产。

对照：[Grok Bot 学习地图](../grokbot-map/) · [2610top40 机制库](../2610top40/)（`kin-human-gate` 同源闸门）。
