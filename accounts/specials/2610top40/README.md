## 怎么读本专题

1. **先看位次与金额**：金额是对方公开晒单，不是我们审计后的财报；作参照，勿当 KPI 承诺。
2. **再看商学院四问**：谁付钱？凭什么被选？漏斗哪一环最强？护城河是否可复制？
3. **再看实战三动作**：本周能跟做的内容/互动/资产沉淀，落到 LIS / 输血 / AI入企 / 小程序。
4. **可学绿边 / 慎学红边**：可学增长与表达机制；慎学币圈投机、互关、虚假紧迫感。
