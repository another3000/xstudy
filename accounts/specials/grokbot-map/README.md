## 怎么读

1. **先开目录帖**：Sawyer 20 课、蓝哥 9×24、Kin 系列目录——收藏的是「导航」，不是单条技巧。

## 慎学清单

- **纯广告 / 代充 / 成品号**：与用法无关。  
- **「Comment XX 领教程 / DM」漏斗**：方法不在公域。  
- **同文案「20 repos / FREE templates worth $XXk」**：收藏虚高，学完仍不会操作。  
- **Cookie 同步、野中转、把客户数据丢进免费模型**：省钱但合规翻车。  
- **只炫截图无步骤**：无 Skill 名、无 Routine 触发、无失败分支。  
- **互关/喊单型**：与 LIS/输血信任售卖相反。
