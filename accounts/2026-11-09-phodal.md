## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **「回到原文核对」** → LIS / 输血信息化：Agent 解读报告或规程时，每条结论必须能点回原字段、原条款；点不回去的标成未验证。
2. **第一周交付物 = 流程堵点图** → AI入企：试点不要先交模型榜，先画「标本从开立到审核卡在哪」，再写未来几周 AI 或实施顾问如何拆。
3. **反差分工句** → 微李玩AI：发「模型可以起草，异常值和规则冲突还得有人兜底」——比「AI 很强」更像现场。
4. **先写 ADR 再让 Agent 狂写** → 小程序：把架构决策记在本地，再给云端 Agent 仓库权限；同时提醒断开会误烧自己额度的连接。
5. **周报要有结论、来源证据和后续行动** → 院内/团队周报：他给 Pero 加的 Insights 不是把对话记录贴上去，而是「这周研究出了什么、哪些还要验证、下周折腾什么」。

## 8. 风险与不该学

- 离职/入职节点帖有巨大曝光，日常账号不要为了流量制造「告别」。
- 连续帮公司喊 HC（工程师、产品、FDE）会把建造者时间线变成招聘板，产品信任会被摊薄。
- 「两天烧完 token，带娃时也不知道 AI 改了什么」是真实体会，但医疗场景里若只卖惨不给复核闸门，会像不负责任。
- 工位照、招呼式引用（「欢迎来指导一下」2438曝 / 1赞 / 书签0）几乎不积累资产。
- 全号历史只有 172 帖，近两周突然变密——**不要误读成「一直这样发就会涨到 5 千粉」**，他靠的是长期开源资产加上职业节点。
