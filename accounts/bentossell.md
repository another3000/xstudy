## 为什么有效

1. **非技术人设降门槛：** 医院行政/科室主任同构共鸣。
2. **视频 + Session 双件套：** 看完还能 copy/paste。
3. **Build in public 真实狼狈：** Bot 不查邮件、拼写错误——增强可信。
4. **书签来自系统图：** 工作台截图比金句更值得藏。
5. **newsletter 商业闭环：** X 是研发日志，邮件是产品。

## 7. 迁到 LIS / 输血 / AI入企 / 小程序

1. **Session 文档** → 每个入企 Bot 一页「复制即用」操作卡（对标 todo-board）。
2. **非技术演示** → 给主任演示「不会代码也能批报告草稿」——人设对齐。
3. **bookmarks→周报** → 用收藏的竞品/政策帖自动起草微李周报。
4. **custom zoho」金句** → 告诉客户：AI 入企常变成「自建轻量业务系统」，预算要含集成。
5. **狼狈公开** → 试点周报写失败次数，反而促续约。

## 8. 风险与不该学

- 医疗不能「vibe」碰生产数据；演示用脱敏。
- 投资/赞助关系需披露。
- 勿用「取代工程师」话术刺激院内 IT。
