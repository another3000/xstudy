## 5. 增长机制拆解

1. **互关 / 粉关比：** ≈3645:1——教科书级健康。关注只有 967，对 352 万粉的老账号极度克制。
2. **回复工时：** 中。长帖会引来上百条讨论（前沿落差帖 878 条回复），他本人不以回复取胜。
3. **钩子话术：** 难以立刻同意的判断句（「距离几乎不可理解」「线在分开而不是靠拢」）、谨慎的数字（<1%、不到支出的 0.1%）、把引用升维成企业结论。
4. **书签型 vs 虚荣赞：** 这是今天五人里最典型的「长论证 = 高书签」。前沿落差帖书签 5393；<1% 采用率帖书签/赞达 0.74。相反，Article 裸链尽管曝光第一，书签只有 202——再一次说明曝光≠被当成参考资料。
5. **权威资产：** Box CEO、BoxWorks 发布、与 NVIDIA 的 Context Retrieval、企业内容权限模型。数字来自客户观察和公开统计（Anthropic 的 Fortune 500 客户平均支出不到其费用的 0.1%）。
6. **跨平台：** X Article、BoxWorks 大会、产品（Architect / Mount / MCP）。
7. **漏斗：** 判断长文建立「这个 CEO 看得到现场」的信任 → 大会日用 Article 摊开四条产品 → 指向 Box 如何给 Agent 提供上下文与文件权限。注意：转化日那条链接本身没有时间线钩子，靠的是既有品牌和 Articles 分发。

## 7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

1. **石蕊试纸** → AI入企 / 微李玩AI：「如果没有 AI 你也能交出同样的东西，说明还没推够。」用它检查演示：检验报告、输血追溯、小程序流程是不是只比人工快了一点，而不是质变。
2. **<1% 采用率口径** → LIS：对医院说「大多数科室还停在单次补全，真正跑在工作流里的 Agent 很少」，既诚实又制造行动理由。
3. **非结构化数据 = 90% 的企业信息** → 输血信息化：配血记录、护士核对、单据影像、科室沟通——Agent 不会的不是模型，是拿不到这些上下文和权限。
4. **岗位从 IC 变成 Agent 管理者** → AI入企：培训材料不要只教「怎么提问」，要教「怎么给 Agent 设刹车、验收和并行任务」。
5. **引用升维** → 微李玩AI：看到一条行业观察，不要停留在转发，补一句「这对医院/老板意味着什么」。

## 8. 风险与不该学

- 裸发 Article 链接：有 Box 品牌和 Articles 分发可以硬吃曝光，我们没有这种表面，复制会得到「没人点」。
- CEO 口吻的宏观判断若没有现场数字，在医疗场景会显得空；他有客户和大会托底，我们要用科室数字托底。
- 不要学「每天一篇超长宏观文」的产能——那是 19 年账号 + 公司观察网络的结果。
- 预测类句子（100X Agent、1000X token）要标明是方向判断，避免被当成承诺。

## 9. 对我们的行动建议

1. 本周发 1 条 **石蕊试纸** 帖：对照一次院内或客户交付，「AI 出现前能否做出同样东西」。
2. 发 1 条 **采用率诚实口径**：我们看见的 LIS/输血场景里，真正嵌入工作流的 AI 还很少，下一步是上下文和权限，不是更炫的聊天窗。
3. 若发长文或更新说明，**推文正文至少写一句论点**，禁止只贴链接。
