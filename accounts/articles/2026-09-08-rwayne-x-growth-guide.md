## 1. 一句话定性

这是一份 **「教资展示完毕 → 开源打法」的增长操作系统**：先甩成绩与共创名单，再讲被看见、主页建设、互动与推荐名单；价值在可复制清单与「别全员写同一套 Codex 技巧」的差异化警告。

## 3. 为什么这篇有效

1. **开源承诺降低防御。** 「教资展示完毕，开始开源」把读者从「又来卖课」切换到「可以抄作业」。
2. **反共识开头。** 在 AI 同质化高峰公开劝人「别都写 Codex」，本身具传播性与道德优势。
3. **哲学段 + 实操段拼盘。** 前半给意义，后半给主页与社交动作——书签动机覆盖「想想清楚」和「今晚改 Bio」两类人。
4. **名单即网络。** 被点名的账号会二次传播；读者得到「关注地图」。
5. **书签远高于赞。** 说明被当成工具书，而非情绪帖。

## 4. 爆款 vs 慎学

| 可学 | 慎学 |
|------|------|
| 成绩前置再开源 | 文内亿级曝光为作者自述——引用时标注来源，勿当第三方审计 |
| 反同质化定位 | 哲学段易写成空泛——微李要落到检验场景差异 |
| 主页建设拆解 | 名单带货感——学结构，勿堆无过滤互推 |
| 「一定要在场」 | 勿滑向纯社交互关 |

## 5. 迁到微李玩AI / LIS / AI入企

1. **冷启动检查表：** Bio 一句业务、置顶一篇可跟做教程、置顶一条现场活人帖——对标「主页建设」章。
2. **差异化一句话：** 「我们不写又一则通用 Prompt，只写检验科能上线的 Agent 闸门。」
3. **学员版开源：** 把入企前 30 天动作开成可勾选清单（对标园长篇可合并用）。
4. **推荐地图：** 维护「可学账号/慎学账号」公开名单（山中学堂已在做）——机制同源。
