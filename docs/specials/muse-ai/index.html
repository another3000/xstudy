学习层 · 机制卡

可学

只读四件套

muse-read-only-first

钩子：任务 + 资料范围 + 完成标准 + 交付；末句写死只整理、不发送、不付费、不联系他人。

为何有效：蓝哥 Article 书签 4102 / 曝光 2.13M；邮件提示词禁止发送与改标签。

本周实验：用公开网页让 Muse 出「附来源资料表」，核对 3 条链接。

可学

发信/花钱人审闸门

muse-human-gate

钩子：Secure VM 可代劳，发送邮件/下单/改权限停在授权卡片。

与 kin-human-gate 同构：可逆链路大胆跑，不可逆人手。

本周实验：指令末句：「任何对外发送与支付必须等人回复确认。」

可学

Secure VM 心智

muse-secure-vm-mindset

「不是豆包，是隔离 Linux + 浏览器」——锚到硬件福利而非空谈 Agent 革命。

可学

Goals 里程碑

muse-goals-loop

多日事建 Goal：交付物 + 缺什么 + 下一步；避免「AI 保证按时完成」幻觉。

可学

目录帖导航

muse-directory-curation

「看这一帖就够了」分路径：注册 / 安全 / 场景 / 官方——目录比散帖更易收藏。

可学

封面贴合官方 IP

muse-cover-match-ip

软萌小熊与官方形象一体，降低认知成本、借官方资产。

可学

生活管家 vs 工作 Bot

muse-vs-work-agent

一句品类词降焦虑：办公多 Bot；日程/家属通知类个人 Agent + 闸门。

可学

组网边界先写清

muse-tailscale-boundary

Tailscale 同网可学；「无限 token」勿作主标题承诺。生产库不对公网 Agent 暴露。

慎学 muse-invite-farm · 邀请码互刷

长文评论区互兑 Token：高回复低信任，与 LIS/输血信任售卖相反。不进必抄，不转发互兑。

慎学 muse-gray-automation · 灰产自动化

全自动撸号 / 白嫖家宽 / 动态白嫖额度——可拆「为何爆书签」，禁止跟做；与客户数据零关联。
