本周必抄机制

人审闸门（Propose don't send）

id: kin-human-gate

可逆链路全自动，不可逆动作（发信/花钱/改预算）写进指令末句必须人批——官方招聘/市场/采购同一闸门。

钩子公式：「Do not contact anyone / 分析可全自动，花钱·发信·改预算必须人批」——把不可逆动作写进指令末句。

本周实验

发 1 条帖（人审后发）：标题意向 「官方教招聘 Bot 最狠的一句：不要直接联系任何人」。
结构：① 抄 Talent Scout 指令末句 ② 对照市场「不改预算」/采购「不自己付钱」 ③ 院内三步：只读巡检→草稿工单→人点确认 ④ 注明 propose don't send、无互关无荐币。

钩子：「Do not contact anyone / 分析可全自动，花钱·发信·改预算必须人批」——把不可逆动作写进指令末句。

Kin《非工程师怎么用好 Grok Bot》汇总官方案例：招聘 Talent Scout 找人、起草私信但明确「不要直接联系任何人」；市场投放给预算再分配建议但「不直接改动预算」；采购 Haggle Bot 调研与比价自做，花钱/接受条款一律人批。共同机制是：可逆链路全自动，不可逆动作人审闸门。这正是 Grok Bot「propose don't send」的产品哲学，也是 LIS/输血信任售卖的底线。

LIS Agent 只读出报告异常并起草工单，改接口配置/发院内邮件必须人点发送。 · 输血 双人复核提醒可自动推飞书，发血决策与对外通知仍需人确认。 · AI入企 PoC Bot 每晚汇总客户通话要点进草稿，客户邮件默认不发送。 · 小程序 运营 Bot 起草活动文案进草稿箱，上架/推送人审。

本专题方法：商学院框架 × 实战派证据——不教炒币，只拆「内容→信任→变现」机制。

怎么读本专题

  1. 先看位次与金额：金额是对方公开晒单，不是我们审计后的财报；作参照，勿当 KPI 承诺。
  2. 再看商学院四问：谁付钱？凭什么被选？漏斗哪一环最强？护城河是否可复制？
  3. 再看实战三动作：本周能跟做的内容/互动/资产沉淀，落到 LIS / 输血 / AI入企 / 小程序。
  4. 可学绿边 / 慎学红边：可学增长与表达机制；慎学币圈投机、互关、虚假紧迫感。
