7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 引用必须补一句成本或分工判断 → AI入企：不要只转「某模型更强」，写清「难题给贵模型，日常文案/改标点用便宜模型；一次重任务大约吃掉额度的多少」。
  2. 版本更新只留「现在能做什么」 → 对照 Hermes v0.23.0：浏览器也能用完整工作区、多入口共用会话、付费 MCP 超上限会再问、安全插件要单独装、手机端仍是 Beta。LIS 发版说明应写成这种可执行清单，而不是「多项优化」。
  3. 认知落差现场 → 微李玩AI / AI入企：写「外面分享会上很多人还只用豆包问问题，我们客户已经在用 Agent 接 WhatsApp/科室消息」——用现场，不用口号。
  4. 一句指令 + 限制条件 → 小程序：像「去申请这个免费云服务器，但要邮箱登录」一样，把坑写在命令旁边。
  5. 创作者账本公开 → 微李玩AI：蓝哥写「1700 多美元 / Ultra 年费约 1000 已 2 倍回本」+ 五条可执行写法。我们可以公开「一条科普视频的工具账」，不要只说「值得做」。
