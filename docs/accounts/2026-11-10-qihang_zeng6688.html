7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 项目写成可验算的小学算术 → LIS / 小程序：上线 N 天、处理单量、单次耗时或客单价、月均——五项里至少写出四项，让读者能自己乘回去。
  2. 先纠正读者可能的误解 → 微李玩AI / AI入企：对照「万兆内核 ≠ 你家网速变成万兆」。院内演示先写清指标口径（测的是什么、不包含什么），再谈效果。
  3. 把过满的结论往回收一档 → 微李玩AI：看到行业大消息，不要写成「某平台已经全面重视我们」；写成「有内容被看到了，所以更值得把案例写清楚」。
  4. 清单前给收藏理由 → 工具盘点可以学「先收藏再看」的明确召唤，但清单必须是自己用过的，不要成为空链接合集。
  5. 评论区里的步骤要转译 → 若看到有用的求职/操作评论，写成自己的步骤并注明来源，而不是只截图说「原来都在评论区」。
