1. 一句话定性

面向已有产品/服务的小老板的小红书 0→1 操作系统：先业务与人群，再选题与制作，再复盘与咨询——每节留下可复用底稿，而不是再囤一篇「养号秘籍」。

  1. 问题开场：一个月认真起号最该做什么？→ 立刻给答案：选题库 + 制作流程 + 复盘记录。
  2. 可执行承诺：四周行动安排写进文内，降低「看完还是不会」的摩擦。
  3. CTA 下放：文末「现在立刻行动」+ Article 卡片。
  4. 外部放大器：权威号引用估价（「能卖399」）→ 二次传播。

3.1 可直接抄的模板（原文精炼）

业务卡

我提供：__。
客户通常在 __ 的时候需要它。
买之前最担心：__。
我能展示的证据：__。

定位句

我帮助【处在什么阶段的人】，在【具体场景】里解决【什么问题】，主要用【什么材料或能力】来讲清楚。

对标五问（拆一篇笔记）

谁会点进来？标题封面让他期待什么？正文拿什么材料兑现？评论还留哪些没解决的问题？若由我来写能补什么新条件或证据？

选题表列：问题原话｜目标读者｜准备怎么回答｜现有材料｜还缺什么｜这篇主要想让读者做什么

演示首批六篇（内容策划服务号）

  1. 只有产品照片，第一篇怎么做
  2. 一段产品介绍拆成三个选题（过程）
  3. 策划 / 代写 / 代运营分别解决什么
  4. 两个人做内容，哪些步骤可先固定
  5. 选题表从问题到材料逐格填
  6. 没案例没专人拍摄，现在适合找外包吗

四周节奏

  • 第1周：方向 + 材料 + 定位/对标/选题底稿
  • 第2周：发一组有区别的内容（别同质刷屏）
  • 第3周：挑一个问题改深（系列化）
  • 第4周：决定继续什么、暂时停什么（复盘卡）

4. 增长与内容机制（这篇教的是什么）

  1. 业务先于平台玩法——养号/日更都后置。
  2. 具体场景人 > 人口统计学标签。
  3. 材料决定选题优先级（具体 + 有材料 + 对准想服务的人）。
  4. 标题兑现正文，封面只承担一个任务。
  5. AI 辅助整理，证据必须本人提供。
  6. 指标拆层，别用「没流量」一刀切判死刑。
  7. 咨询与交付说明比宣传语具体——内容漏斗接到生意。

5. 可学习清单 → 微李玩AI / LIS / AI入企

  1. 业务五空写进置顶 → 「微度 LIS 帮检验科解决 __；客户上线前最怕 __；我们能展示的证据是 __（上线前后对比/科室试点）」。
  2. 定位句收窄 → 别写「所有学 AI 的人」；写「已有 LIS/检验信息化、两人负责推广、不知道第一批科普发什么的小团队/科室」。
  3. 选题先记原话 → 收集院方/检验科真实问句（「血透数据怎么对」「报告互认怎么讲」），再写标题。
  4. 首批六篇结构迁移 → 换成本职：只有现场照片怎么发科普；一次客户介绍拆三题；LIS / 代实施 / 代运营区别；两人团队固定流程；选题表演示；没案例时要不要外包拍片。
  5. 四周行动当内容日历 → 下周起按「备料→差异发布→改深→取舍」排「老李玩AI」片单。
  6. 书签型长文也可发 X Article → 把检验/AI入企「可照做」流程做成 Article，利于收藏而非只追短帖曝光。

6. 风险与不该学

  • 原文演示账号是虚构贯穿，不要把演示数据当作者实测。
  • 「一个月起号」是行动框架，不是保证涨粉公式。
  • 小红书平台规则（蒲公英、开店资质、社区公约）以官方为准，旧门槛别当死规则。
  • 医疗/LIS 内容须真实依据，勿为点击编功效或夸大。

7. 对我们的行动建议（本周）

  1. 填一张微李玩AI 业务卡 + 定位句（检验科普 / AI入企 二选一先主攻）。
  2. 建选题表，至少塞进 10 条真实原话问题。
  3. 按「首批六篇」骨架列出 6 个标题候选，本周只做出 2 篇有材料的。
  4. 发完留版本卡：标题/封面/用途/时间，方便对照这篇第九章做复盘。
