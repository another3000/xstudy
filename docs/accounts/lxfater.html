7. 可学习清单 → 微李玩AI / LIS / AI入企

  1. 对照实验数字 → AI入企：试点「有清单 vs 无清单」差错率/周转时间，发帖必须带一组数。
  2. Demo → 清单二连 → 微李玩AI：先发 15 秒检验场景 Demo，次日发「8 个可复用 Skill/提示词」。
  3. 保姆级置顶 → 学 Clawdbot 置顶逻辑：一条「从 0 接到微信/飞书提醒」长文常驻。
  4. 业务数据接入叙事 → LIS：别空谈 Agent，列「先接哪 4 个数据源」（对标微信/飞书/X/Gmail）。
  5. 开源策展带「我以前的做法」 → 安利工具时先交代自己的旧路径，降低广告感。

8. 风险与不该学

  • 人生鸡汤/抱怨厂商封号：流量蜜、专业形象砒霜（检验/政企尤甚）。
  • 「微信数据库解密」等灰区操作：演示可以，对客户勿鼓励违规取数。
  • 高频贩卖焦虑（提前学了白学）：可用一次，周更会像贩卖恐惧。
