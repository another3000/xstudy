7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. Small tip 句式 → 微李玩AI：每周 1 条「小提示：把检验科普页做成可安装 PWA/小程序」。
  2. 公开步骤 + 原始输入 → AI入企：演示 Agent 时贴「用了哪些院内字段/日志」，对标 EHT 原始数据叙事。
  3. 费用/轮次透明 → 发「2 小时 140 turns ≈ $x」降低 AI 落地神秘感。
  4. 金句只作引流层 → 可发短句，但主资产必须是 tip/演示。
  5. 作品>身份 → Bio 极简，靠连续实验建立信任——适合「老李玩AI」现场感。

8. 风险与不该学

  • 天文/艺术实验娱乐性强，迁医疗时要换成「可审计步骤」语言。
