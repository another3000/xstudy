为什么有效（机制因果）

  1. 美元是通用语言。 -$124、$600+、$1.7k、$137K/m——读者不需要理解你的栈，也能感到利害。医疗场景可换成「人时/差错/耗材」，机制相同。
  2. Build in public 的可证伪版本： 不是「我很励志」，而是账单截图、key 数量、locale 数。怀疑者可以质疑方法，很难否认数字来源感。
  3. 杀依赖叙事 > 炫富叙事： 「cutting dependencies」把省钱上升为自主权哲学，避免纯炫富反感，同时合理化 vibe coding 一天自建。
  4. 损失帖建立「自己人」： $1.7k 被刷比成功案例更易互动——幸存者分享坑，粉丝给建议，关系变深。

8. 风险与不该学

  • 过度晒 MRR 在医疗/政企语境易显轻浮——改成「结果指标」而非个人收入。
  • 「一天 vibe coding 替掉 SaaS」低估合规与安全；对客户承诺要加边界。
  • 公开求情/抱怨平台（Yubikey 帖）娱乐向，品牌号慎用。
