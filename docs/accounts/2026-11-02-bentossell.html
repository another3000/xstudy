7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 标准清单式征集 → 微李玩AI：「什么样的院内 AI 试点算健康？」列 4 条（人审/日志/回滚/不炫技）征集同行。
  2. 建造日记屏录 → LIS：录「异常标本 Agent 编排」30s + 可抄 prompt。
  3. 脆弱但有边界的阶段汇报 → AI入企：季度「我们卡在合规/数据口径」公开信，求建议但不卖惨。
  4. X bookmarks → 内容管道 → 小程序/内容：把收藏夹变成周更素材库（他在建的 newsletter 管道可迁）。
