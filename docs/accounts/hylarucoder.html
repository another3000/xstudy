7. 可学习清单 → 微李玩AI / LIS / AI入企

  1. 「刚好够用」工具叙事 → 微李玩AI：别卖「全能平台」，发「科室只要这 3 个按钮」的自造小工具演示。

  4. 短梗漏斗 + 长帖承接 → 热点吐槽后 24h 内补一篇「我们怎么落到检验场景」。
