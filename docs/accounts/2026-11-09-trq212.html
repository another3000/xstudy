7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 对照句打中两种人 → 微李玩AI：「会写规则的老师觉得自己要过时，行政同事却恨自己不会向模型提问」——让两边都觉得被说中。
  2. 把狂热写成回避 → AI入企：如果科室天天让 Agent 改提示词、流程却从未上线，点明这是假忙碌，并补一个「本周必须上线的最小闭环」。
  3. 可粘贴的场景提示词 → LIS / 小程序：学他的位置提醒结构，改成「标本超过 N 小时未核收，工作日某人回到岗后 30 分钟提醒，直到确认或延期」。
  4. 未完成作品也公开进度 → 产品开发：dock 帖的诚实（还有很多边界、暂不推荐用）比「我们已全面智能」更可信。发一版带限制条件的演示。
  5. 让 Agent 做一部分，熟手在熟悉的工具里接续 → 小程序 / 院内工作站：不要强迫医生改用全新界面；给现有系统加 MCP/接口，让 Agent 填一部分，人在老工具里改完。
  6. $200 已经够用，智能只会更便宜 → 微李玩AI：劝团队先用现在的套餐跑通一个任务，而不是等无限额度。

8. 风险与不该学

  • 652 万曝的离职信靠的是 Claude Code 光环，普通账号发告别信不会有这个数字。
  • 纯金句（courage < genius）传播好看、动作缺失，专业号发多了会像鸡汤。
  • WoW / 格斗游戏进度对「微李玩AI」可以借鉴「公开做一件自己真正想做的东西」，但不要直接发游戏角色和法术 build。
  • 「inshallah」一类宗教/模因补句不必学，跨文化容易误读。
  • 「解决方案是更加 AGI-pilled」偏信仰宣言，企业客户要的是验收标准，不是站队。
  • 40 万粉会把中等帖也推到十万级曝光——学习机制时要按书签率而不是按他的绝对数字来设预期。
