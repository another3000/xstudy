7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 「预知危险」叙事 → AI入企：发「Happy Path 之外医院对接最易炸的 5 个点」，先虑败。
  2. 产品演示短视频/截图 → 小程序定制：发「加了某某交互前后对比」，可感知交付。
  3. 故障即内容 → LIS：「某接口推送全挂」复盘渗透与依赖。
  4. 反潮流一句立场 → 微李玩AI：「我不让客户全自动改生产配置」+ 三条护栏。
  5. 可复现工作流抬书签 → 输血信息化：发可点开的核对清单/脚本，而非只发金句。
