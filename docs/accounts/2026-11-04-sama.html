7. 可学习清单（→ 微李玩AI / LIS / AI入企 / 小程序）

  1. 边界一句当资产 → 微李玩AI：固定发「AI 不替代医师签字/人审闸门」红线帖，目标高回复+可引用。
  2. 产品发布模板 → 小程序：名+一句话收益+硬链；学 Dots 结构。
  3. 预告留白 → AI入企：试点上线前发「我们发现一个新交付件」吊胃口，次日给证据。
  4. 过程透明维修信任 → LIS：对误报/故障发「审查进行中+外链纪要」，对标 agents 审查帖。
