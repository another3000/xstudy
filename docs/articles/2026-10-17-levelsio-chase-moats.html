1. 一句话定性

这是一篇 「AI 大公司吸走软件层之后，我还剩什么」的自述式护城河清单：专有数据、网络效应、分发、物理/IRL、资本、监管——并给出每个桶里他正在做的具体动作与部分收入数字。

3. 为什么有效

  1. 框架清晰。 读者可把自己的业务往六个桶里丢——天然书签。
  2. 数字挂动作。 API 定价、邮件列表规模、X 分成量级——账本感强。
  3. 承认软件护城河变薄。 与独立开发者焦虑共振，但不贩卖绝望，给迁移路径。
  4. 2022 AI scramble 类比。 个人史连贯，增强「他会真的转向」可信度。
  5. 书签 4235。 创业者收藏「盘点表」，不是迷弟点赞。

5. 迁到微李 / LIS / AI入企

  1. 帮客户盘三件套： 数据（谁产生、能否 API 化）、分发（谁能随时触达）、交付关系（现场/驻场/硬件）。
  2. 反堆工具： 提案先写护城河桶，再写用哪个模型。
  3. IRL 资产： 沙龙、装机、科室共建——对标 Meetup/Hotelist 的「人不在云上」。
  4. 会说不： 明确不接的监管/擦边项目，写进定位。

6. 本周动作

  1. 画一页「我们的护城河六格」，每格最多写 3 条证据。
  2. 找出 1 个只存在于线下的资产，本周做一次可见化（纪要/短视频）。
  3. 检查是否过度依赖「可被大模型吞掉」的纯软件功能卖点。
