# xstudy

每天拆一位创作者 / AI 实战账号的笔记库（X 及其他平台）。

## 怎么用

1. 复制 [`TEMPLATE.md`](./TEMPLATE.md) → `accounts/YYYY-MM-DD-handle.md`
2. 用公开数据填表（粉丝、近 7 日发帖、代表帖链接与互动）
3. 写完「可学习清单」时，必须落到 **微李玩AI / LIS科普 / AI入企** 可执行动作

## 目录

- `TEMPLATE.md` — 固定十段结构
- `accounts/` — 按日一篇拆解
- 样板：[`accounts/2026-10-24-tiezhuthinker.md`](./accounts/2026-10-24-tiezhuthinker.md)

## 每日例行

由 Grok Bot 例行「每日一位创作者拆解」按本模板产出，再入库。
